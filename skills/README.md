# Project skills

Use [All in One maintenance](all-in-one-maintenance/SKILL.md) for app development, regression checks, local releases and knowledge updates. The repository instructions point Codex and Claude to it when they work here.

Use [Plan page](plan-page/SKILL.md) before a large or risky change: write the plan as a short blog-style page, get the owner's approval, then build.

## Office work

The six office skills cover everyday document and data work.

| Skill | Use it for |
|---|---|
| `excel-automation` | Clean, combine, calculate and format workbooks, with checked totals |
| `powerpoint-design` | Storyline, one message per slide, layout, type, colour, visual check |
| `word-professional` | Structure, styles, contents page, tables, captions, page setup |
| `formal-writing` | Emails, reports, requests and replies in clear, polite English |
| `deep-summary` | Long PDFs and big topics into a layered summary with page references |
| `data-to-insight` | Numbers into a checked finding: answer, evidence, cause, action |

How they connect: `data-to-insight` finds the answer, `formal-writing` words it, and the Excel, Word and
PowerPoint skills produce the file. `deep-summary` feeds any of them from long source material.

## Install

Copy the six folders to `%USERPROFILE%\.claude\skills\`. Claude then loads each skill by itself when a task
matches its description.
